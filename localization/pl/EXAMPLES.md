# Przykłady polskich tłumaczeń

| Oryginał | Polski |
| --- | --- |
| `New Game` | `Nowa gra` |
| `Continue Game` | `Kontynuuj grę` |
| `Options` | `Opcje` |
| `Paused` | `Pauza` |
| `[use] Continue` | `[use] Kontynuuj` |
| `Press [fire] to fire your weapon` | `Naciśnij [fire], aby strzelić z broni` |
| `Press [grab] to pick up objects` | `Naciśnij [grab], aby podnieść obiekty` |
| `Press [age] to age soldiers` | `Naciśnij [age], aby postarzyć żołnierzy` |
| `Press [health] to use <font color='#FF9900'>Health Packs</font>...` | `Naciśnij [health], aby użyć ... <font color='#FF9900'>apteczek</font>...` |
| `Your current objective is shown on the pause menu.` | `Bieżący cel jest wyświetlany w menu pauzy.` |

Tokeny wejścia i znaczniki Scaleform pozostają bez zmian, aby runtime mógł
wyświetlać aktualne symbole PSVR2.
