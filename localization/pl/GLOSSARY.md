# Glossary

This glossary is the shared terminology for the first Polish UI/tutorial
batch. Symbolic input tokens such as `[fire]` stay unchanged; the VR layer can
render the appropriate PSVR2 glyph or text at runtime.

| English | Polish | Note |
| --- | --- | --- |
| TMD | TMD | Keep the established acronym. |
| E99 | E99 | Energy/resource name. |
| Katorga 12 | Katorga 12 | Proper location name. |
| Singularity | Singularity | Game/proper name. |
| age | postarzyć | TMD action that advances an object's age. |
| revert | odmłodzić | TMD action that returns an object toward its earlier state. |
| renew | odnowić | Used for crates and medkits. |
| Impulse | Impuls | TMD force action; use as a verb where Polish grammar requires it. |
| Chronolight | Chronolight | Proper device name. |
| ping | ping | Scanning function; keep the short technical term. |
| Deadlock | Deadlock | Named weapon/object. |
| Revert | Revert | Enemy name; do not translate as a normal verb. |
| Zek | Zek | Enemy name. |
| Tick | Tick | Enemy name; “kleszcz” can be considered later for subtitles. |
| Mutant | mutant | Generic enemy class. |
| melee | atak wręcz | Close combat action. |
| weapon | broń | Generic weapon term. |
| shotgun | strzelba | Weapon class. |
| machine gun | karabin maszynowy | Weapon class. |
| reload | przeładować | Action verb. |
| objective | cel | Mission/objective UI label. |
| checkpoint | punkt kontrolny | Save/checkpoint terminology. |
