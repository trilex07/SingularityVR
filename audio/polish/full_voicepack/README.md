# Full Polish voice working set

Generated from the current Polish localization draft on 2026-10-08.

- 894 player-facing entries rendered as mono 24 kHz WAV;
- each row is linked to its original localization `id` in `manifest.jsonl`;
- generated level is normalized to -3 dBFS peak;
- no original game package or `Coalesced_INT.bin` was modified;
- the current localization draft routes 890 generic UI/tutorial entries to the user voice narrator and 4 Barisov-labelled entries to the Barisov profile.

This is the complete audio working set for text that currently exists in the Polish draft. The original story SoundNodeWave corpus contains additional spoken lines whose Polish transcript is not present in `full_draft.jsonl`; those require the separate audio extraction/transcription pass before they can be safely voiced and redirected. The manifest deliberately keeps this distinction instead of assigning invented dialogue to those assets.
