# Changelog

## 1.0.0 — 2026-09-06

First release.

- Setup wizard with opt-in PC detection
- Game research and coverage check; framework research with license check and build-on/from-scratch decision
- Environment modes (agentic / desktop / chat) with switching and friction-triggered re-pitch
- Stages 0–10 with exit criteria, effort labels, and gate procedure
- Method for finding hook points in unknown engines
- Controller family table including Steam Frame; connection-method table
- Structured HUD/UI conversion (inventory → classify → build → layout mode)
- Implementation loop with feature flags, safe mode, config validation
- Four-layer test process, in-game assertions, fixtures, nausea protocol
- Bug pipeline with in-VR capture, screenshots, severity rules
- Manifest and bindings JSON shapes; status board; glossary
