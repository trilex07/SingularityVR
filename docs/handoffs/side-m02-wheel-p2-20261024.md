# M02 P2: default-OFF weapon wheel skin (SIDE / offline)

P2 is a separate commit and acceptance gate after P1. `[Render] UiRemasterWheel=0` defaults OFF and does not require `UiRemasterSettings=1`. It replaces the existing round wheel's graphics only when the four known catalog guns are identified and all atlas assets are ready. Otherwise the accepted wheel renderer executes. Input, sector math, owned-weapon gating and commit behavior remain unchanged.

The neutral atlas supplies the wheel chassis and four original weapon silhouettes (Centurion 5799, Valkyrie 11387, Volk/Spikeshot 8297, Kasimov 11389). The PL/EN atlas supplies the center hub. The selected sector gets a ring; unowned sectors remain unnamed and without a weapon icon. The overlay returns before the accepted wheel drawing, preventing a second floating wheel in the normal successful path. It uses the existing right-hand projection and `wheel_layout::RoundMetrics` per eye.

The only numeric ammo display is for the currently held gun. It reads reflected `mClipAmmo` and `mBinAmmo` from the current HUD object; unknown or invalid values remain blank. Counts for holstered guns are deliberately not fabricated.

All three atlas files are the same as P1, placed under `Binaries/vr-assets/ui/remaster/`. On any failure set `UiRemasterWheel=0` and verify the previously accepted wheel. P2 is not physical PASS from these offline tests.
