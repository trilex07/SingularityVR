# Seeker SIDE asset handoff (offline candidate)

Private package: `build/seeker-private/final_handoff/` in the dedicated SIDE worktree. It contains original cooked/decoded source, source PSK/PSA, exact and PBR GLBs, 4K maps, an updated 64 px wheel atlas, previews, validation and SHA-256 manifests. None of these game-derived bytes are committed.

## What is ready

- The Seeker wheel illustration was edited from the verified original PSK silhouette. The private atlas replaces only `dev-seeker` at `(256,128,64,64)`; all other atlas pixels compare byte-for-byte after decode. It retains the existing catalog ID, ownership gate, and selection path. Its 1024 px transparent master and the approved generated-art master are in the private package.
- Source rig GLB preserves all 85 bone names and parent relationships. Its 54-frame, 24 FPS `Reload` reference drives descendants only; the weapon/controller root remains static. The source magazine is 410 triangles in the `clip` subtree with zero cross-boundary triangles. Separate origin-centered magazine GLBs preserve the original clip-local pivot. The socket manifest contains the source bind matrix, not a fitted hand offset.
- 4096×2048 UV-compatible maps carry authored machining height, microtexture and material response. The HD GLBs embed albedo, packed metallic/roughness, and a glTF Y-converted tangent normal. The private standalone normal PNG retains DirectX Y. The native shader binding and metallic mask require visual review before use. The same-light comparison shows only a modest visible difference; **HD visual acceptance is not met**. Geometry in the current HD GLB is source-exact, with no added modeled detail.
- Offline structural validation passes for GLB import, source rig/animation, separated magazine, maps, tangent normal lengths and atlas isolation. Blender 5.2.3 imported, saved `.blend`, exported and reimported both GLBs with matching triangle counts, magazine hierarchy, 4K images and reload action. The round-trip artifacts are in `clean/`. This proves file integrity, not visual quality or live placement.

## Native reload gate

`Shared_ARSteerable` is a heavy `RvWeaponShared_RocketLauncher`, with `ERAT_ARSteerable`. That class inherits through `RvWeaponShared_RememberProjectile` to `RvWeaponShared`; neither intermediate class defines a script reload override. The owned Singularity PE (`BD459ACD87D4B82693928DEE4ED437C086D5928A8E0428F3AD54B6FC114C0F51`) maps both RocketLauncher and base `RvWeaponShared` vtable slot `0x4C4` to `0xEA3710`. The private `source/reload_contract_audit.json` records this evidence. The original Seeker PSA has 54 frames. **These facts do not establish that a live Seeker reload increases clip and decreases reserve.** The archived decompressed PE text witness and a same-transaction authoritative clip/reserve receipt were unavailable to SIDE.

A default-OFF `SeekerManualReload` candidate is now connected to the existing native refill permit and left-hand carry path. It requires the existing `ReloadRefillOnly`, `ReloadNativeMagazine` and `ReloadPalmGrip` gates. The source PSK/PSA, original GPU palette and measured 410-triangle magazine are cached in `runtime/`; 1704 source pose samples match the CPU oracle. The 54-frame source clip, cover, release, trigger and bullet children remain independently movable. The ejection axis is measured from source frame 12; insertion requires a continuous rear corridor and compatible orientation, so a front or side shortcut cannot seat the magazine. The weapon root remains controller-owned. The separate palm mount comes from the original noTMD glove mesh fit, with zero triangle intersection in the tested grip pose. The optimized x86 PE32 DLL is an **offline candidate only**, packaged as `runtime/d3d9.offline-candidate.dll` and never deployed.

Before enabling the candidate in MAIN, record one legitimate source Seeker reload with local weapon identity, authoritative clip/reserve before and after, and native acknowledgment. A shared method pointer or animation notify alone is insufficient. Then test rear insertion, front/side refusal, empty reserve, full clip, cancellation, switching, reset, per-eye replay and guided fire in Steam/PSVR2. MAIN owns this acceptance and no SIDE deployment was attempted.

## Reproduce private package

Run the three `tools/seeker` builders against the SHA-pinned private PSK/PSA, original texture PNGs and atlas. `build_seeker_icon.py` also requires the approved generated-art master at the hash pinned in that script. For native caches run `prepare_weapon_animation.py` with the Seeker PSK, PSA, original cooked vertex/index buffers and texture; its report pins every FNV witness. Run `tools/seeker/test_seeker_offline.ps1` and `tools/reload/test-seeker.ps1`, then `spikes/view_matrix/build.ps1 -GameBinaries <private-game-binaries>`. Run Blender 5.2.3 background with `-P tools/seeker/validate_blender_scene.py -- <private-handoff>` and finish with `finalize_seeker_package.py --worktree . --private build/seeker-private`. Source files, generated textures and built DLL remain private.
