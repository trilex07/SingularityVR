## Actual change and matrix contract

Default-OFF `[Input] DualHandActionPose=1` enables the candidate in the existing
right-handed dual-TMD context. Only four measured ordinary weapon profiles are
eligible (5799, 11387, 8297, 11389); Seeker and unknown meshes keep their baseline.

`PrepareIndependentLeft` captures exact original TMD material-0 wrists: slot 1
is bone 9, slot 19 is bone 51. Capture happens before independent-hand edits,
isolation, finger changes or eye transforms. Shadow draws cannot seed it.
The witness is keyed to render frame, pawn, weapon and profile. Invalid source,
nonuniform/sheared/singular scale, missing tracking or owner mismatch rejects it.

Original PSK ancestry and first named PSA `idle` frame provide reference wrist
frames. They are generated by `tools/reload/prepare_dual_hand_reference.py` into
`dual_hand_reference.h`; no guessed offset, mesh or complete animation is added.
The generator uses the same root conjugation / Y convention as `armbind`, not
raw exported vertex space. Private PSK/PSA inputs remain outside Git.

Row-vector convention, original skin S, bind B, local-to-world L, controller ride C:

    J = B * S
    D = inverse(J * L) * (J_reference_scaled * L)
    C_corrected = D * C
    J * L * C_corrected = J_reference_scaled * L * C

The native uniform component scale is preserved. All descendants keep their
current relative animation, since the same rigid parent correction is applied.
The wrist-parent animation itself is deliberately removed; do not claim every
native visual wrist recoil is preserved. Native shot spread/recoil, damage,
TMD energy, input and power gates are untouched.

`BuildGunC` and the independent controller builders consume the same current
source correction. `LocalDeltaPair` cancels the actual draw ride, not a surrogate,
so the correction is applied once. The older free-right-wrist translation fix
is bypassed only when this new witness is valid, avoiding a second correction.
The existing common TMD assembly/sleeve route receives one left-hand delta;
there are no bone-selection, IB, mesh, material or draw-dispatch changes.

Support, holster, knife/magazine carrying, native cinematic/healing/restraint
owners, menu, pause, left-handed and invalid-tracking contexts retain old paths.
Support still requires the actual Grip plus existing distance/tracking/weapon
latch. L2 and Square do not set that latch. No binding changes were necessary.
