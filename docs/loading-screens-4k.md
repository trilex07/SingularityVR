## Remaining pipeline (MAIN)

1. DXT1 encoder + full mip chains for the 11 masters (no texconv /
   ImageMagick on PATH; Pillow cannot write DDS). C++ tool, L1-verified
   round-trip + header/budget gates per prepare-material-remaster.py dds().
2. Encode 11 x 4096x2048 DXT1 + 13 mips, verify, stage (binaries NOT committed).
3. Targets: 11 new entries for targets_generated.h (AUTO-GENERATED by SIDE
   texture_pipeline.py — coordinate; file mirrored repo/assets copies must
   stay identical) + group decision (no loading/ui group exists yet).
4. Rebuild dinput8 (stable hash changes), install DDS + DLL pair with backup,
   L3 visual verify per loading screen.

Splash.bmp (boot file) is a separate path (plain file, not injector) — out
of scope for the DDS pipeline; decide separately.
