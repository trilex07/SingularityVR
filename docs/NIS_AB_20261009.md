# NIS A/B checkpoint — 2026-10-09

The seven commits from `research/nvidia-vr-upscaling` are integrated on
`fix/vr-menu-input-grip-performance`. The shipped INI now contains an explicit
`[Upscaling]` section; the default remains `Mode=Off`.

The first Steam run with `Mode=NISSharpen` loaded the embedded official NVIDIA
NIS 1.0.3 scaler and sharpen shaders and reached a measured frame:

```
mode NISSharpen, sharp 0.35, renderScale 1.00, outScale 1.00
eye in 2112x2304 -> out 2632x2684
GPU mean 0.324 ms, stage copy mean 0.007 ms, 1 frame
lifetimes: shaders 1, stage 1, outputs 1
```

This is an initialization smoke sample, not a headset performance claim. The
same run had no active SteamVR controller profile (`UI 0`, both hands inactive),
so it cannot validate menu input.

The stage copy is currently ~0.007 ms in the sample. Keep the safe staged-SRV
path for now. The requested direct-SRV-on-shared-texture experiment is only
worth implementing after a longer A/B capture confirms that the copy is a
material part of the 90 Hz frame budget and that the source texture exposes a
valid SRV lifetime.
