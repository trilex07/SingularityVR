# Material remaster review package

Generated by `asset-tools/textures/material_remaster.py`. Full report:
`docs/MATERIAL_REMASTER.md`.

## Contents

| path | what |
|------|------|
| `weapon_shotgun/` | AR_shotgun (first-person shotgun) |
| `glove/` | inview_glove (first-person glove) |
| `env_door/` | door_blastdoorN (blast door, environment) |
| `<asset>/manifest.json` | per-material manifest: checksums, mip0 proof, DDS validation, fidelity, evidence labels |
| `<asset>/*_diffuse_2x.dds` | enhanced diffuse, real DXT, full mip chain |
| `<asset>/*_normal_2x.dds` | enhanced normal, real DXT, signed-downsampled mip chain |
| `<asset>/*_specular_review.dds` | enhanced specular for review only, **not** injected |
| `<asset>/comparison/*_compare.png` | A/B sheets: original / Lanczos upscale / remastered |
| `manifest_summary.json` | roll-up of the three manifests |
